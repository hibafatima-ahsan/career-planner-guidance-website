# Career Planner Guidance

A beginner-friendly Flask web application for a Career Guidance system.

## Features

- Student career profile
- Education information
- Skills
- Interests
- Career goal
- Career recommendation
- Recommended skills
- Career action plan
- Counselor review panel
- JSON career dataset
- Sample student dataset

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
- Jinja2
